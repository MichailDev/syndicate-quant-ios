# Историческая база: топ-лиги за последние 3 сезона

Версия по умолчанию проверяет следующие национальные чемпионаты:

| Лига | SStats ID | Сезоны |
|---|---:|---|
| England Premier League | 39 | 2023/24, 2024/25, 2025/26 |
| Spain La Liga | 140 | 2023/24, 2024/25, 2025/26 |
| Italy Serie A | 135 | 2023/24, 2024/25, 2025/26 |
| Germany Bundesliga | 78 | 2023/24, 2024/25, 2025/26 |
| France Ligue 1 | 61 | 2023/24, 2024/25, 2025/26 |
| Russia Premier League (RPL) | 235 | 2023/24, 2024/25, 2025/26 |

Год сезона в SStats — стартовый год: `2025` означает сезон `2025/26`.

Для каждой пары лига/сезон установлен лимит 500 матчей, поэтому полноценный сезон не обрезается лимитом 300. Фактически будет обработано столько завершённых матчей, сколько доступно в SStats.

Проверка выполняется walk-forward: для исторического матча используются только данные, доступные до него; результаты не подмешиваются в прошлое. Это верификация, а не ML-обучение.

Автоматический интервал по умолчанию — 168 часов (раз в неделю), чтобы не перегружать API. При первом запуске `AUTO_BACKTEST_ON_START=true` стартует полная историческая проверка в фоне.
